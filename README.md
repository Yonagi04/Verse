# Verse

Verse 是一款统一的 LLM 网关系统，旨在为不同的用户和租户提供不同LLM服务的接入和路由。它支持多种 LLM 提供商，并提供统一的接口和管理功能。

## 为什么需要 Verse？

在现代应用中，LLM（大语言模型）服务的需求日益增长。然而，不同的 LLM 提供商有不同的接口、认证方式和使用限制，这给开发者带来了集成和管理上的挑战。
此外，不同的LLM Application需要支持不同类型的接口（如 OpenAI、Anthropic 等）。
Verse 通过提供一个统一的网关，简化了这些复杂性，使开发者能够轻松地接入和切换不同的 LLM 服务。用户/租户只需要申请一个统一的 API Key，就可以访问网关内已注册的不同 LLM 服务，而无需关心底层的实现细节。

## 主要功能

- 统一的 LLM 接入和路由
- 多租户支持，每个租户可以配置自己的 LLM 服务
- 支持多种 LLM 提供商（如 OpenAI、Anthropic 等）
- 提供统一的 API 接口，简化开发者的集成工作
- 提供管理界面，方便用户和租户管理自己的 LLM 服务配置
- 支持自定义路由规则，根据请求内容选择合适的 LLM 服务
- 提供日志和监控功能，帮助用户了解请求的处理情况和性能指标，评估 Token 消耗
- 支持降级和容错机制，确保在某些 LLM 服务不可用时仍能提供服务

## 技术栈

- **编程语言:** Java 21
- **框架:** Spring Boot 3
- **构建工具:** Maven
- **数据库:** MySQL
- **缓存:** Redis
